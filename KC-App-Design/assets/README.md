# UI 素材库

KC 批量建库工具的可复用设计素材。页面以 Pixso 中的画板为视觉基准，素材按需取用，不要求每页都放贴纸。

## 目录

| 目录 | 数量 | 内容 |
| --- | --- | --- |
| `backgrounds/` | 2 | 画板底层实际嵌入的 1280×800 背景：P1 用粉色网格猫，P2–P5 用天空猫 |
| `screen-stickers/` | 16 | 已被具体页面使用的裁切贴纸：登录页 4 枚、P2 装饰组 4 枚、P3 类型卡片图标 4 枚（128px）及其 1x 原图 4 枚 |
| `stickers/handdrawn/` | 23 | 手绘猫咪：窗口、耳机、信封、书本等 |
| `stickers/pixel/` | 22 | 像素功能图标：铃铛、文件夹、软盘、垃圾桶等 |
| `stickers/watercolor/` | 17 | 粉色水彩贴纸：文件夹、显示器、笔记本电脑等 |
| `stickers/pixel_kawaii/` | 21 | 猫咪像素贴纸：云朵、信封、软盘、文件夹组合等 |
| `stickers/extra_a/` | 15 | 粉色猫咪 UI 元素：窗口、浏览器、标签、对话框、便签、天空窗 |
| `stickers/extra_b/` | 17 | 场景与复古元素：加载窗口、UFO 猫、梦境窗、播放列表、复古软盘/信封/错误框 |
| `previews/` | 6 | 素材总览图，供评审浏览；不参与应用打包 |

全部 **115 枚透明 PNG** 的路径、尺寸、来源和裁切框记录在 [`sticker-library.json`](sticker-library.json)。

`stickers/extra_a/manifest.json` 与 `stickers/extra_b/manifest.json` 保留各自批次的生成来源。

## 背景

| 文件 | 用途 |
| --- | --- |
| `backgrounds/background-pink-grid-cat-1280x800.jpg` | P1 登录页底层背景，已按 1280×800 等比裁切 |
| `backgrounds/background-sky-cat-1280x800.jpg` | P2、P3、P4、P5 底层背景，已按 1280×800 等比裁切 |

背景不进入任务表、输入框和按钮内部；画板底层叠加白色柔化蒙层以维持文本对比度，叠放顺序为插画 → 白色柔化蒙层 → 内容。

## 贴纸使用约定

- P1：左上窗口猫、右上星星彩虹、左下行星、右下笔记本电脑，均位于卡片外留白。
- P2：星星、猫咪文件夹、猫咪软盘与云朵四枚，沿画板右下留白横向排列，不遮挡任务表、日志条或状态栏。
- P3：顶部四张类型卡片用贴纸作图标——记事本（新建 Topic）、猫咪文件夹（新建 Map）、猫咪软盘（搭建 Pub）、信封（导入图片）。

界面文字统一使用 **Noto Sans TC** 的 Regular / Bold 两个字重。
