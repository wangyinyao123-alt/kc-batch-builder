## 导出步骤

1. 用有权限的 Pixso 账号打开 [pixso-source.txt](../pixso-source.txt) 里的链接。
2. 选中画板，导出 PNG，1x 原尺寸；视觉评审可另出一份 2x。
3. 按上表文件名放进本目录。
4. 可选：导出整份 PDF 作为 `../preview.pdf`，一次看完全部 6 页。

导出后请以源稿为准做视觉验收；`design-tokens.json` 中的数值是近似值，精确尺寸、间距、字号以 Pixso 检查模式为准。
