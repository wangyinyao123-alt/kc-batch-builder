# 交互与状态说明

## P1 登录

- 首次使用：标题上方显示“本机首次使用，请先登录”。
- 默认：服务器地址预填且可修改；用户名、密码、记住密码；主按钮“登录”。
- 登录中：按钮改为“正在连接…”并禁用，避免重复提交。
- 密码错误：按钮下方显示密码错误提示。
- 连接失败：按钮下方显示连接失败原因。
- 会话失效：显示“登录已失效，请重新登录”。
- 不提供注册、忘记密码或跳过登录。

## P2 任务中心

- 顶栏：应用名、环境“测试”、连接状态、头像、账号名、切换入口。
- 空态：显示“还没有任务，点右上角新建”。
- 列表列：任务名、类型、状态、进度条、操作。
- 状态：执行中、已完成、排队中、部分失败。
- 同一时间最多允许一个任务执行；其他待执行任务必须进入排队状态。
- 部分失败行显示“查看原因”。
- “+ 新建任务”打开 P3。

## P3 新建任务

- 类型四选一：新建 Topic、新建 Map、搭建 Pub、导入图片。
- 默认交付变体为“搭建 Pub”，包含框架 Excel、已有 Topic/Map KC 路径、发布输出格式、语言。
- 目标目录需要格式校验；非法或不存在时在输入框下显示红字。
- “预检”先验证字段和落点；预检失败时在按钮上方显示汇总，并可展开明细。
- “开始执行”仅在必填字段有效且预检通过后可用。

### 导入图片链路（对接 kc-import-images 脚本，接口细节见 backend/kc-import-contract.md）

- 本地图片：设计稿“多选”落为“选择文件夹”（Electron 原生目录对话框）；“包含子文件夹”为勾选框，勾选后标题自动带目录前缀。
- KC 目标路径：文本框手贴 + 「浏览目录」按钮（打开目录树对话框，逐层展开）；手贴内容按 Normalize-KcPath 规则清洗（去引号 / `/`→`\` / 压连续 `\` / 规范 General 开头）。
- 落点校验：浏览或手贴后，若目标文件夹类型不是“图片”（ISHIllustration），输入框立即转 error 态并提示“这层不能放插图，请选到 \image 层”。
- 模式：「导入」只补 KC 没有的（同名跳过）；「更新」同名替换内容（幂等，哈希相同自动跳过）。更新模式下可选“只替换，不新建”、“替换前备份原图”（默认开）、“导出名称/GUID 对照表”（默认开）。
- 两段式执行：「预检」= 只读跑一遍（零写入），出汇总（新建/更新/无变化/跳过/阻塞/失败）+ 逐项清单；用户确认后「开始执行」才真正写入。预检出现“阻塞”项时，需用户显式确认放行（-IgnoreStateGate）才能继续。
- 同名判定键：标题 NFKC 归一 + 去空白 + 小写，不做模糊匹配。批内重名直接判失败。
- 结果分组：成功 = 新建 + 更新；需处理 = 失败 + 更新未校验（已写入但回读没对上，须单独列出）+ 阻塞。
- 产物：执行后可“打开落点”查看日志 transcript、滚动台账、GUID 对照表、更新备份目录。

## P4 任务详情

- 顶部：返回、任务名、类型标签、状态标签。
- 进度区：总进度、已完成数量、当前步骤名。
- 标签页：预检报告、执行日志、结果清单。
- 状态：预检中、执行中、成功、部分失败。
- 部分失败：失败项单独分组，提供“查看原因”和“只重试这些”。
- 底部操作：暂停、取消、只重试失败项、导出结果、打开落点。
- 执行日志需要支持持续追加和滚动定位。

## P5 设置

- 服务器地址。
- 默认落点白名单。
- 记住密码开关。
- 日志保留天数。
- 版本号和“检查更新”。
- 操作：恢复默认、保存设置。
- 设置保存后应有明确成功反馈；非法服务器地址或白名单路径需要字段级错误提示。

## D1 弹窗

### 危险确认

取消正在执行的任务时，明确说明：已创建对象保留在 KC 仓库；当前处理项停止并标记为未完成；排队项不会开始；未完成项之后可重试。

### 报错详情

显示标题、原因和错误码；提供“复制详情”和“确定”。复制详情应写入系统剪贴板，并给出成功反馈。
