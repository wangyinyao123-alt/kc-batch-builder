## 四脚本共性（待验证的假设）

导入图片脚本确认的架构约定，其余三个脚本到齐后逐一对照：

- Electron 主进程永远以 headless 方式调用（给全参数 → 不弹 Windows 窗体）
- stdout 逐行日志协议（`STEP N` / `[OK]` / `[X]` / `[预检]` / `[结果]`）→ 主进程解析器按行消费
- 两段式：先预检（不带 Commit，零写入）→ 用户确认 → 执行（带 Commit）
- 认证：账号密码参数传入；登录失败主动停止降级防锁号
- 目标平台 Windows（powershell.exe）；macOS 开发走 mock runner 回放录制日志

其余脚本如形态不同（比如 Node 脚本、exe），以实际脚本为准更新本节。
